# EdTech-Analytics-Dashboard
This project focuses on analyzing recorded lecture data collected from multiple EdTech platforms to uncover insights related to course demand, learner engagement, instructor performance, language preferences, and skill trends.


Business Problem

The EdTech company wants to expand its recorded lecture services but lacks insights into:

Which categories and subcategories have the highest learner demand.
Which course types generate maximum engagement.
Which languages learners prefer for different categories.
How course duration impacts views.
Whether subtitles improve learner engagement.
Which instructors consistently deliver high-quality content.
Which skills are currently trending in the education market.
Objectives

The dashboard provides insights into:

1. Course Distribution Analysis
Analyze course count by:
Category
Sub-category
Course type
Identify categories with the highest availability and learner interest.
2. Viewer Engagement Analysis

Calculated:

Average views by:
Category
Sub-category
Language

Purpose:

To understand which courses attract maximum learner engagement.

3. Skill Trend Analysis

Identified:

Most frequently taught skills.
Category-wise skill distribution.

Purpose:

To ensure course offerings align with current industry requirements.

4. Language Distribution Analysis

Analyzed:

Distribution of courses across different languages.

Insights:

Understand accessibility preferences.
Identify opportunities for multilingual content creation.
5. Category-wise Language Preference

Analyzed language preferences for the:

Top 5 categories based on learner demand.

Purpose:

Help clients optimize content localization strategies.

6. Subtitle Impact Analysis

Studied relationship between:

Subtitle availability
Course views

Purpose:

To evaluate whether subtitles improve accessibility and learner engagement.

7. Instructor Performance Analysis

Identified:

Top 3 instructors based on ratings.
Category-wise and subcategory-wise instructor performance.

Purpose:

To identify high-performing educators for future collaborations.

8. Course Duration vs Views Analysis

Analyzed:

Relationship between course duration and learner views.

Duration conversion rules applied:

Monthly courses:
1 month = 60 hours of content
Flexible schedules:
Converted to 200 hours

Purpose:

Understand learner preference for short vs long-duration courses.

9. Skill Diversity Impact Analysis

Analyzed whether:

Number of skills offered in a course/category

affects:

Learner views and engagement.

Purpose:

Determine whether broader skill coverage attracts more learners.
